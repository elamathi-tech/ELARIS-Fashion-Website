# ELARIS – Fashion Website

ELARIS is a responsive fashion and e-commerce website built as a front-end web development project. The website provides a clean and modern shopping experience with different fashion collections and interactive features.

## ✨ Features

* 🏠 Home page
* 🆕 New Arrivals section
* ⭐ Most Wanted section
* 👗 Collections page
* 🔍 Product search functionality
* 🎯 Product filtering by:

  * Occasion
  * Color
  * Arrival
* 📱 Responsive design for mobile, tablet, and desktop
* 🍔 Responsive mobile navigation menu
* 📩 Contact form with validation and success message
* 📧 Newsletter subscription section
* ❤️ Product wishlist buttons
* 🎨 Modern UI using Tailwind CSS
* 🔗 Navigation between different pages

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Tailwind CSS
* SVG Icons

## 🔍 Collections

The Collections page includes products that can be searched and filtered based on different categories.

### Filters

* **Occasion**

  * Summer
  * Party
  * Beach

* **Color**

  * Red
  * Blue
  * White
  * Green

* **Arrival**

  * New
  * Old

Users can also search products using the search bar.

## 📱 Responsive Design

The website is designed to work across different screen sizes, including:

* Desktop
* Tablet
* Mobile

Tailwind CSS responsive utilities are used to create the responsive layout.
